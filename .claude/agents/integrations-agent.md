## Стандарты слоя

### Устойчивость к внешнему миру
Внешний API — недоверенный и ненадёжный источник. Обязательно:
- **Таймаут на каждый запрос.** Явный, из конфигурации, а не «по умолчанию httpx».
- **Retry с экспоненциальной задержкой и джиттером** на транзиентных отказах: сетевые ошибки, `429`, `5xx`. Число попыток ограничено. `4xx` кроме `429` не ретраится — это не транзиентный отказ.
- **Уважение `Retry-After`**, если заголовок пришёл.
- **Потолок параллелизма** к каждому маркетплейсу (`asyncio.Semaphore`) — иначе планировщик выест рейт-лимит за один проход.
- **Единый `httpx.AsyncClient`** передаётся снаружи и переиспользуется. Создание клиента на каждый запрос — дефект: теряется пул соединений.
- Ограничивай размер читаемого ответа. Неограниченное чтение чужого тела — вектор DoS.

### Честная деградация
- Клиент возвращает `None` (или доменный результат отказа) при отсутствии данных и **логирует причину с достаточным контекстом**: артикул, маркетплейс, HTTP-статус, категория отказа.
- **Молчаливое проглатывание — блокирующий дефект.** `except Exception: pass` запрещён. Отличай в логах: товар не найден, рейт-лимит, блокировка антиботом, изменение формата ответа, сетевой сбой. Оператор должен по логу понять, что произошло, без отладчика.
- Для Ozon блокировка антиботом (403, капча, HTML вместо JSON) — **ожидаемый режим**, а не исключительная ситуация. Распознавай его отдельно и сообщай наверх различимо: «источник временно недоступен» ≠ «товара нет».
- `NotImplementedError` и заглушки, притворяющиеся успехом, запрещены.

### Разбор ответа
- Ответ внешнего API валидируй схемой Pydantic из `app/schemas/`, а не цепочкой `.get()` с `None` в конце. Схема — контракт; её нарушение логируй как изменение чужого API.
- Никогда не приводи к типу без проверки: `int(price)` на `None` даёт `TypeError` в проде. Проверяй до преобразования.
- Деньги — целое число копеек.
- Не доверяй порядку элементов и наличию вложенных ключей.

### Безопасность
- URL внешнего API — константа или значение из конфигурации. Пользовательский ввод попадает только в параметры запроса, и только после валидации типа. Подстановка пользовательской строки в хост или путь — SSRF.
- Заголовки и прокси — из конфигурации. Никаких секретов в коде.
- Не логируй ключи, токены и полные заголовки авторизации.
- Проверку TLS не отключай.

### Типизация
Полная типизация, `mypy --strict` обязан проходить. Абстракция `BaseMarketplaceClient` — единственная точка, через которую доменный слой знает о маркетплейсах; не протекай httpx-типами наружу.
