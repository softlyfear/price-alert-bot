# robots.txt маркетплейсов

Снимки `robots.txt`, на которые опирается выбор источников цены. Файл — добровольное соглашение
для роботов: он говорит, куда ходить можно, но доступа не даёт; антибот работает отдельно.

## Ozon — `ozon.ru.robots.txt`

- Источник: `https://www.ozon.ru/robots.txt`, снят 2026-10-09.
- Получение: без cookie сайт уходит в круг `307` с `?__rr=N`; с сохранением cookie между
  запросами — `200`, `text/plain; charset=utf-8`, 12 940 байт, 254 строки.
- Отличие от оригинала: убраны пробелы в конце строк 23 и 130 (`Disallow: /brand/[0-9]+$/`),
  иначе их снимает хук `trailing-whitespace`. sha256 оригинала:
  `661b8425037042a6ed83775f4f9a18ebdeeeed7358f59cd27758792c193261aa`.

Что значит для бота (блок `User-agent: *`):

- `/api/entrypoint-api.bx/...` в файле не упоминается — по правилам `robots.txt` не запрещён.
- `/product/...` не запрещён; запрещён только `/category/*/product$`.
- Запрещены, но боту не нужны: `/webapi/`, `/search`, `/auth/`, `/my/...`, `/context/...`.
- `Crawl-delay` нет.
- Технически API при этом закрыт антиботом: замер 2026-10-09 — `403` с JSON
  `incidentId`/`challengeURL` (`challenge.html`), данных товара нет.

## Wildberries

Снимка нет: `https://www.wildberries.ru/robots.txt` из скрипта 2026-10-09 отвечает `498`
(страница антибота, 1 128 байт), `https://card.wb.ru/robots.txt` — `403` с пустым телом.
Нужно сохранить файл из браузера и положить сюда как `wildberries.ru.robots.txt`.
